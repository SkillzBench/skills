# blender-asset-qa

[![SkillzBench](https://skillzbench.com/api/badge/blender-asset-qa)](https://skillzbench.com/skills/blender-asset-qa)

Mandatory review gate for any mesh or asset created or edited in Blender. Detects z-fighting, floating/detached parts, inverted or inconsistent normals, non-manifold/open geometry, degenerate faces, duplicate verts, n-gons, unapplied scale, UV problems, bad skin weights, material/texture errors, and renders multi-angle review sheets. Use before calling any modeling, export or delivery task done.
