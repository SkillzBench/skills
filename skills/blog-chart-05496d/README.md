# blog-chart

[![SkillzBench](https://skillzbench.com/api/badge/blog-chart-05496d)](https://skillzbench.com/skills/blog-chart-05496d)

Internal capability, not user-invocable: the orchestrator calls it while running blog-write or blog-rewrite to turn research data into dark-mode compatible inline SVG charts (horizontal bar, grouped bar, donut, line, lollipop, area, radar) for HTML or MDX. Produces accessible markup (role=img, aria-labelledby, unique ids), source attribution and transparent backgrounds. Agents cannot call it.
