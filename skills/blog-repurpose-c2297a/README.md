# blog-repurpose

[![SkillzBench](https://skillzbench.com/api/badge/blog-repurpose-c2297a)](https://skillzbench.com/skills/blog-repurpose-c2297a)

Turn an existing blog post into draft text for other channels: X threads, LinkedIn posts, Threads/Bluesky, short-video scripts, YouTube scripts, Reddit posts, newsletter excerpts, podcast scripts. Saves drafts to files; it never posts anywhere. Never invents personal stories or results: first-hand framing appears only when the user supplies it. Use when the user says "repurpose", "turn this post into a thread", "linkedin post from blog", "youtube script from post". Not for writing the blog post itself (blog-write) or scheduling.
