# molted

[![SkillzBench](https://skillzbench.com/api/badge/molted)](https://skillzbench.com/skills/molted)

Add email (sending, replying, reading a test inbox) to an agent you're building, using Molted's agent-native email infrastructure. Use when the user wants to give their agent an inbox, send transactional/agentic email, read/classify inbound replies, or asks "how do I add email to my agent". Not for generic email best practices (deliverability, DMARC, spam) - see the other skills in this repo for that.
