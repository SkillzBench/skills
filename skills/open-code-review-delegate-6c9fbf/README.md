# open-code-review-delegate

[![SkillzBench](https://skillzbench.com/api/badge/open-code-review-delegate-6c9fbf)](https://skillzbench.com/skills/open-code-review-delegate-6c9fbf)

Review workspace changes, PRs, commits, or branch comparisons with the host agent's model. OCR's CLI selects files and resolves rules; the host reviews them for defects and explains changes that affect users or callers. Use when the user has no separate API key for OCR or wants to reuse their coding-agent subscription or model setup. For OCR's full native pipeline with its own model provider, choose open-code-review instead.
