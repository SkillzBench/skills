# open-code-review-delegate

[![SkillzBench](https://skillzbench.com/api/badge/open-code-review-delegate)](https://skillzbench.com/skills/open-code-review-delegate)

Review workspace changes, PRs, commits, or branch comparisons with the host agent's model. OCR's CLI handles file selection and rule resolution; this skill defines the review workflow, coverage requirements, and output format. Use when the user has no separate API key for OCR or wants to reuse their coding-agent subscription or model setup. For OCR's full native pipeline with its own model provider, choose open-code-review instead.
