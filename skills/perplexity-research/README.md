# perplexity-research

[![SkillzBench](https://skillzbench.com/api/badge/perplexity-research)](https://skillzbench.com/skills/perplexity-research)

Brain-augmented web research. Asks Perplexity about a topic, with a short summary of what the brain already knows, and returns what is NEW with citations. Sends page content only after the user agrees. Use for current-state checks and freshness deltas on topics. NOT for simple URL fetches (use web_fetch) or brain-only queries (use gbrain query).
