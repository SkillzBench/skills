# reactivity-diagnostics

[![SkillzBench](https://skillzbench.com/api/badge/reactivity-diagnostics)](https://skillzbench.com/skills/reactivity-diagnostics)

Map a Solid 2.0 dev diagnostic code (STRICT_READ_UNTRACKED, REACTIVE_WRITE_IN_OWNED_SCOPE, LOADING_ON_OUTSIDE_HOLD, HOT_SCOPE_*, ...) to its repair. Use when a Solid console warning, test failure or @solidjs/diagnostics artifact reports a [CODE].
