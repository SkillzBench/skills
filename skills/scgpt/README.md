# scgpt

[![SkillzBench](https://skillzbench.com/api/badge/scgpt)](https://skillzbench.com/skills/scgpt)

Embed and annotate single-cell expression data with scGPT, a foundation model for single-cell biology. Use this skill when: (1) Producing cell embeddings from an AnnData for clustering/integration, (2) Zero-shot or fine-tuned cell-type annotation, (3) Gene-level representation for perturbation/GRN tasks.
