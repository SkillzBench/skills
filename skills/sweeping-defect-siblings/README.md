# sweeping-defect-siblings

[![SkillzBench](https://skillzbench.com/api/badge/sweeping-defect-siblings)](https://skillzbench.com/skills/sweeping-defect-siblings)

Turn one reported defect in ffmpeg-skill into the full list of places the same thing happens — naming the defect's class (an input property, a shared step, a convention that differs between two code paths, an FFmpeg-version behaviour), sweeping every tool with tests/sweep.py and a path-parity probe, separating decided refusals from real siblings, and landing the fix with one regression test per class rather than per report. Use whenever an issue or PR comment reports a bug in this repository, before writing the fix, and again when triaging an external review or audit.
